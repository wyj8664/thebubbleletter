Drawing guide

How to Draw a Bubble Letter Q

Start with a simple capital Q shape, then draw a rounded outline around each stroke. Keep the corners soft, make the outline thick enough for coloring, and leave generous white space inside the letter so it stays readable. For lowercase q, use the same rounded bubble style with a shorter, friendlier shape.
