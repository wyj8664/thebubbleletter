# Bubble Letters Notes

- `Sticker Bubble` is an original Canvas rendering style for the generator, not a downloaded paid font. It still needs visual refinement later: softer character shapes, more intentional highlight placement, and better resemblance to hand-drawn black bubble sticker letters without copying any commercial font.
- Keep using licensed/self-hosted fonts only. Avoid adding personal-use-only bubble fonts unless a commercial license is purchased and checked for web app/generated image output.
